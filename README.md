# Privid - 3D Virtual IoT & Embedded Systems Laboratory

An interactive educational web platform built for engineering students and IoT developers to explore, inspect, and master microcontrollers, sensors, communication modules, and electronic circuits in immersive 3D.

## ✨ Features
- **3D Component Studio**: High-fidelity interactive 3D models with 360° orbit rotation, zoom, studio white view, and layer explode.
- **Interactive Pinout Callouts**: Tap any header pin or terminal to inspect multiplexed functions (GPIO, ADC, PWM, I2C, SPI, UART) and voltage specifications.
- **Comprehensive Hardware Library**:
  - **Dev Boards**: ESP32 DevKit, ESP32-CAM, ESP8266 NodeMCU, Arduino Uno, Raspberry Pi 4.
  - **Sensors**: BMP280, MQ-2, MPU6050, IR Obstacle, Soil Moisture, GPS NEO-6M, RFID RC522, DHT11/DHT22, Ultrasonic HC-SR04, PIR Motion.
  - **Basic Electronics**: LED, Resistor, Electrolytic Capacitor, Push Button, Potentiometer, Piezo Buzzer, Solderless Breadboard.
  - **Communication**: HC-05 Bluetooth, nRF24L01+ RF, SIM800L GSM/GPRS.
- **Simulated Real-Time Telemetry**: Live interactive sensor telemetry data and waveform graphs.
- **Student-First Interface**: Beginner connection rules, pin safety warnings, and wiring diagrams.

## 🚀 Getting Started
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
